# Химия вокруг нас

Мой небольшой учебный сайт из двух страниц по химии. На первой странице находится таблица Менделеева, а на второй — карточки с описанием элементов.

## Что внутри проекта
- `index.html` — первая страница с таблицей Д. И. Менделеева.
- `tablitsa.html` — вторая страница с карточками элементов (название, символ, номер, свойства и где применяется).
- `images/` — папка, где лежат картинки для сайта (`брейнрот`).

## Как запустить
1. Скачать файлы проекта к себе на компьютер (или склонировать репозиторий).
2. Открыть файл `index.html` в любом браузере (просто нажать на него два раза мышкой).
3. Переключаться между страницами можно по ссылкам сверху.
